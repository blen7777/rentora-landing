# Rentora — Plataforma SaaS para Centroamérica

> Production-ready landing page for Rentora built with **Next.js 14**, **MySQL**, and **Drizzle ORM**.  
> Includes a modern, flat premium UI and a database-backed **Contact Form** for lead capture.


---

## 🎯 Overview

**Rentora es una solución tecnológica integral para la administración profesional de empresas Rent a Car.
Nuestra plataforma permite controlar reservas, contratos digitales, inventario de flota, reportes financieros y facturación electrónica en cumplimiento con la normativa local.
Más control, más eficiencia, más crecimiento.
